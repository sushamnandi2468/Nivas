| Status | Meaning |
|---|---|
| `Not started` | No implementation work has begun. |
| `Started` | Scaffold, design, or an initial implementation exists; the feature is not usable end-to-end. |
| `In progress` | Core implementation is underway, but tests, dependencies, or the phase gate are incomplete. |
| `Complete` | Implemented and validated against its defined acceptance criteria. |
| `Deferred` | Intentionally postponed by an accepted decision; it must be scheduled again before pilot release. |
| `Blocked` | Cannot continue until a named dependency, approval, or environment prerequisite is resolved. |
