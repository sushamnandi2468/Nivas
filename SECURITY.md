# Security Policy

NivasOps takes the security of residential communities, tenant data, and operational systems seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in NivasOps (particularly regarding tenant isolation, PostgreSQL Row-Level Security bypasses, authentication, or cryptographic challenge integrity):

1. **Do not create a public GitHub issue.**
2. Send an email directly to **sushamnandi2468@gmail.com** with the subject `[SECURITY] Potential vulnerability in NivasOps`.
3. Include detailed steps to reproduce the issue, proof of concept, and any affected versions or configurations.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an assessment and timeline for a patch within 5 business days.
- Once fixed, a security advisory and patched release will be published.
